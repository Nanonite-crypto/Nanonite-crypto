## Projects

### [JARVIS](https://github.com/Nanonite-crypto/jarvis)
Voice-controlled AI assistant that lives on the PC. Dual-brain — a fine-tuned local Qwen3 model handles everyday conversation, with Groq cloud fallback for harder questions. Voice in, voice out, long-term memory engine, optional Tauri desktop UI, and a bridge to Claude Code for self-modification.

### [pc-control-mcp](https://github.com/Nanonite-crypto/pc-control-mcp)
Model Context Protocol server that gives Claude full Windows control: mouse, keyboard, screenshots, windows, Playwright browser automation, notes, clipboard. 30+ tools.

### [glowup-tracker](https://github.com/Nanonite-crypto/glowup-tracker)
RPG-style PWA for tracking fitness, nutrition, and skincare habits. Vanilla HTML/CSS/JS, localStorage, service worker, installable on iPhone. I use it every day.

### Forge (retired)
AI-powered app generator I built and deployed on my own Hetzner server (Next.js, Claude Agent SDK, Stripe, Nginx, PM2, Let's Encrypt, PostgreSQL). Ran it for a while, then took it down when server costs outgrew its value as an experiment. Learned more about production deployment and Linux operations from running and breaking it than any tutorial would have taught me.
